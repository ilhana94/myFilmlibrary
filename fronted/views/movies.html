UserService.init() method: Checks if the user is already logged in (via user_token in localStorage). Set up jQuery Validate for the login form. UserService.login() method: Sends a POST request to: Constants.PROJECT_BASE_URL + "auth/login". generateMenuItems method: Retrieves the user_token from localStorage. Decodes the token using Utils.parseJwt() to extract the user object. Checks if the user and their role exist If the user has a role: Depending on the role (USER_ROLE or ADMIN_ROLE), it dynamically generates: Navigation bar items (nav) specific to that role and main page sections (main) that should be displayed. Injects the generated nav into the element with ID #tabs. Injects the generated main sections into the element with ID #spapp. If no valid token or role is found: Redirects the user to login.html (forces login) On success: Saves a token to localStorage. Redirects to index.html. On error: Shows error using Toastr. If this is students.html file that is created in pages folder
